## 📥 安装

### 步骤一：添加扩展仓库

打开 Mihon，进入 **设置 → 浏览 → 扩展仓库**（Extension repos），点击 `+` 添加下面这个地址：

```
https://raw.githubusercontent.com/SaltedFishRocketLauncher/laimanhua-mihon/repo/index.pb
```

> 索引为 protobuf 格式（`index.pb`），即 Mihon 当前版本使用的标准扩展仓库格式。

### 步骤二：安装图源

回到 **浏览（Browse）→ 扩展（Extensions）**，下拉刷新，找到「来漫画」点击安装。

### 步骤三：开始阅读

安装完成后进入 **浏览 → 图源（Sources）**，即可看到「来漫画」。热门、最新、分类、榜单、搜索都能直接使用。

<details>
<summary><b>无法安装或装上没反应？</b></summary>

1. **确认仓库地址用的是 `index.pb`**。旧版 `index.min.json` 在新 Mihon 上已不被支持，请改用上面的新地址。
2. **添加仓库后务必下拉刷新**扩展列表，否则可能看不到新图源。
3. **更新扩展时如报签名冲突**，先在扩展详情里移除旧版本再安装。
4. 部分网络环境下 `raw.githubusercontent.com` 可能加载缓慢，可稍后重试。

</details>

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🔥 热门 | 合并站点首页全部 15 个榜单区块，按 URL 去重，一次看全 |
| 🕒 最新更新 | 走分类页翻页，每页 30 条，按更新时间倒序 |
| 🏆 漫画排行 | 15 个榜单表头切换，名称与原站标题一一对应 |
| 🗂️ 漫画分类 | 17 个分类翻页浏览，最多支持 1800+ 页 |
| 🔍 搜索 | 拼音首字母定位 + 跨字母缓存模糊匹配，缓解漏词 |
| 📖 详情页 | 读取 `og:*` 结构化信息：标题 / 作者 / 封面 / 简介 / 状态 / 更新时间 |
| 📑 章节列表 | 自动解析，兼容多种站点模板 |
| 🖼️ 图片加载 | 解析内联 `picTree`，三级图片主机容错 + 指数退避重试 |
